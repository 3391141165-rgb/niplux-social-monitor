选了“最近 7 天”，数字是什么意思？
只纳入最近 7 天发布的已采集帖子，展示这些帖子截至采集时的累计浏览和互动。它不是账号过去 7 天新增的总浏览。
“—”和“0”有什么区别？
“—”代表平台没有返回数据；“0”代表返回值为零。部分缺失时会标注“部分数据”，不能把缺失当成没有表现。
为什么两个模块的帖子数不同？
搜索和内容类型只筛选帖子复盘页及导出文件。首页、内容分析和竞品观察始终按上方品牌、平台及发布时间范围计算。
工作台会替我发布内容吗？
目前提供采集、查看、比较和导出。发布帖子、回复私信、安排定时发布仍需在 Meta / Instagram 中操作。

    


    
数据口径与采集范围
采集范围：Facebook 近 30 天、最多 50 条；Instagram 最近 50 条以内。选择 90 天或全部时也仅显示已采集的样本，不会补齐平台历史。
变化仅比较同一账号、两次均采集到且有数值的相同帖子。它不是完整自然日增量，新增或不再采集的帖子不计入变化。
关注者未跨平台去重；Facebook 观看人数使用独立媒体观看者，Instagram 触达使用 reach，不宜直接等同或跨帖子去重相加。
“—”表示指标未返回；部分数据只汇总已返回值。Facebook 互动 = 回应 + 评论 + 分享，Instagram 使用 API 返回的总互动。
